## Exam rules

1. Set a 90-minute timer and use no notes.
2. Answer every question. Some items say **Select TWO**.
3. For PBQs, write the ordered configuration or evidence plan before checking the solution.
4. Score one point per numbered item. A multi-select item is correct only when all required choices are correct.
5. Review every wrong answer and label the cause: knowledge, interpretation, calculation, or time pressure.

## Readiness gate

Do not memorize forms. Space attempts apart and use the answer keys only after submission. A practical readiness target for this course is at least 85% on three unseen forms, completion of the PBQ tasks, and the ability to explain why the distractors fail. This is a course benchmark, not a published CompTIA passing formula.
