# Career Extension — Junior Network Support

This path adds job-facing context that commonly surrounds networking. It is deliberately separate from the N10-009 exam chapters. None of these lessons turns the course into CCNA/CCNP, advanced Windows administration, cloud architecture, or DevOps training.

## Scope guard

| Included | Not included |
|---|---|
| Verify addressing, DNS, routes, ports, logs, and basic service dependency | Advanced directory design, trusts, or identity architecture |
| Read and make a small approved firewall/VPN change in a lab | Vendor certification, advanced threat prevention, or large policy design |
| Understand a basic cloud packet path | Multi-region enterprise cloud architecture |
| Read simple YAML/JSON and review a planned change | Programming frameworks, CI/CD platform engineering, or advanced automation |
| Document, test, roll back, and escalate | CCNP-level BGP/OSPF policy, MPLS design, or complex redistribution |
